# Support

## How to file issues and get help

This project uses [GitHub Issues](https://github.com/microsoft/Autoruns-for-Linux/issues)
to track bugs, feature requests, usage questions, and other requests for help.
Search existing issues before opening a new one, and include the Autoruns
version, distribution, architecture, command, and relevant output or diagnostic
rows when reporting a problem.

Do not report security vulnerabilities in a public issue. Follow the private
reporting instructions in [SECURITY.md](SECURITY.md).

## Microsoft Support Policy

Support for this project is limited to the community resources listed above.
This project is not covered by a Microsoft Customer Service and Support (CSS)
support contract unless Microsoft states otherwise in a separate agreement.
